# Changelog — gpt55-adversarial

## 1.0.0 — 2026-04-28

### Added

- Initial release using GPT-5.5 for adversarial document review
- Replaces `gpt52-reasoning`, which is now deprecated
- Renamed to align with the actual model (`gpt-5.5`) and category (`adversarial`); the legacy name `gpt52-reasoning` had been running on `gpt-5.4` since 0.7.0
- Prompt and verdict vocabulary copied verbatim from `gpt52-reasoning` v1.0.0 to preserve consumer contract
